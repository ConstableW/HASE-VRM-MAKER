# HASE VRM MAKER

Eigenständiges Desktop-Produkt zur Erstellung, Bearbeitung, Animation, Verwaltung und zum Export hochwertiger, individualisierbarer 3D-Charaktere (zentrales Exportformat: VRM 1.0). „HASE“ ist ausschließlich der Produktname.

**Projektstatus:** Konzeptphase (Discovery & Architecture). Kein Produktcode. Architekturfreigabe steht aus (Product Owner).

**Einstieg:** [`AGENTS.md`](AGENTS.md) → [`docs/08-handoffs/CURRENT_STATE.md`](docs/08-handoffs/CURRENT_STATE.md)
