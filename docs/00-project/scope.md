# Scope

**Maßgebliche Quelle für Umfang und Abgrenzung.** Details der Funktionen: `requirements.md` (IDs), später `../01-product/feature-catalog.md`.

## Im Zielumfang (OWNER DECIDED, Mandat 2–4)

Speziesoffene Engine (Archetype/Species/Character) · Package-System (Body/Species/Asset) mit SDK und Package Builder · Gesichtseditor · Körpereditor · Haarstudio · Kleidungseditor · Materialsystem · Expert-Modus (Mesh, Sculpt, Morph, UV, Material, Rigging/Weights, Physik, Animation/Posing) · Rigging/Retargeting · Animation inkl. VRMA, Expressions, Viseme, Spring Bones · Export/Validierung (VRM 1.0, Prüfung glTF/GLB/FBX) · UX (Wizard, freie Bearbeitung, Verlauf, Vergleich, Barrierefreiheit) · Projektverwaltung.

Priorisierung (P0–P3 in `requirements.md`) legt nur die Reihenfolge fest und streicht nichts.

## Gegenwärtige Phase: Konzept

**In dieser Phase:** Konzept, Recherche, Spezifikation, Planung, Dokumentation.

**Nicht in dieser Phase (ohne gesonderten Auftrag):** Produktimplementierung, technische Spikes, Releases, Beschaffung kostenpflichtiger Ressourcen, Commits/Pushes (REQ-GOV-001/-002).

## Nicht-Ziele (OWNER DECIDED bzw. aus Mandat ableitbar)

- Technische Kopplung an Home Assistant / HASEC / andere HASE-Produkte.
- Übernahme geschützter Assets, UIs oder proprietärer Implementierungen der Referenzprodukte.
- Spiel- oder Runtime-Engine für Endanwendungen (Charakter wird erstellt und exportiert, nicht als Spiel betrieben). *ASSUMED – bitte bestätigen.*

## Offen

Zielgruppen und Verwertung (OQ-06), Online-Dienste (OQ-07), Lizenzmodell (OQ-02).
