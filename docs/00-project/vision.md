# Vision

**Maßgebliche Quelle für die Produktvision.** Herkunft: Mandat 1 (OWNER DECIDED, siehe `owner-decisions.md` OD-001…OD-004).

HASE VRM MAKER ist ein eigenständiges Character Creation Studio: die intuitive, visuell hochwertige Charaktererstellung moderner MMORPGs, verbunden mit der Bearbeitungstiefe professioneller 3D-Software und einem offenen, package-basierten Spezies- und Asset-Ökosystem.

**Nutzererlebnis:** Charakter erstellen → individuell gestalten → bei Bedarf detailliert nachbearbeiten → technisch prüfen → unmittelbar verwenden.

**Leitsatz:** Maximale kreative Freiheit für den Nutzer; die Engine übernimmt die technische Komplexität (Rig-Anpassung, Kleidungsfitting, Validierung, Export).

## Funktionale Referenzen (keine Vorlagen)

| Referenz | Beitrag zur Vision |
|---|---|
| AION 2 | Gestaltungsfreiheit, detaillierte Gesichts-/Körperanpassung, hochwertige Echtzeitdarstellung |
| Guild Wars 2 | Zugänglichkeit, Charakteridentität, Presets, intuitiver Prozess |
| VRoid Studio | Nachträgliche Detailbearbeitung, spezialisierte Werkzeuge, VRM-orientierter Workflow |
| Blender / DCC | Technische Tiefe, Asset-Pipelines, Erweiterbarkeit, nichtdestruktive Konzepte |

Analyse und Schlussfolgerungen: `../04-research/references.md`.

## Abgrenzung

- Kein VRoid-Klon, keine vereinfachte Blender-Oberfläche, kein schneller Avatar-Generator (REQ-PROD-007).
- Keine künstliche Beschränkung auf wenige Körperformen, starre Presets oder eine Handvoll Schieberegler (Mandat 1.2).
- Keine Abhängigkeit von Home Assistant, HASEC oder anderen HASE-Produkten (REQ-PROD-001).

## Qualitätsanspruch

Vollwertiger, langfristig erweiterbarer Character Creator. Die Architektur trägt die gesamte Vision; die Umsetzung erfolgt inkrementell (REQ-PROD-005).
